# Changelog

## 0.3.0

- Added seed-level matched interaction contrasts and 95% confidence intervals.
- Added supported complementarity, substitution, and inconclusive classifications.
- Added facility backlog, arrival pressure, and arrival concentration diagnostics.
- Added Pareto verification metrics for retained nondominance, hypervolume, and degradation.
- Added scenario-specific reoptimisation and fixed-policy congestion and cost comparisons.

## 0.2.0

- Reconstructed shuttle, pre-event, information-awareness, and joint-policy
  mechanisms from the supplied appendix.
- Added optional OSM coordinate movement, position logs, and density maps with
  duration fallback when source JSON is missing.
- Added capacity-dependent complementarity/substitution analysis.
- Added experimental design, optional XGBoost and quadratic surrogates,
  dependency-free NSGA-II, and Pareto exports.
- Added sensitivity and robustness workflows, scenario configurations, tests,
  provenance notes, and public-release safeguards.

## 0.1.0

- Reconstructed the baseline S0 simulation as an installable Python package.
- Added deterministic replications, aggregation, CSV/JSON outputs, and plotting.
- Added safe fallback behaviour for missing OSM walking-time files.
- Added tests, documentation, and a GitHub Actions workflow.
